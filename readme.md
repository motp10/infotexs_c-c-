# Logger

Многопоточная библиотека для записи сообщений в лог с различными уровнями важности.

## Сборка

Полная сборка проекта:

```bash
make
```
Сборка библиотеки:

```bash
make library
```

Сборка приложения:

```bash
make app
```

Очистка временных файлов:

```bash
make clean
```

## Запуск
```
build/bin/logger_app --file output.log        --level default_level
```

Библиотека находится в:

``` build/lib/liblogger.so```


## Архитектура

Проект разделён на несколько компонентов:

logger/ — основная логика логирования и уровни важности сообщений.
messages/ — сообщение и потокобезопасная очередь сообщений.
worker/ — рабочий поток, отвечающий за обработку и запись сообщений.
argument_parser/ — обработка аргументов командной строки.
message_parser/ — обработка пользовательского ввода.
main.cpp — точка входа приложения.

## Требования
GCC
GNU Make
